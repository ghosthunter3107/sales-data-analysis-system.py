# Project 4: Sales Data Analysis System

**Difficulty Level:** Beginner (BTech Project)

**Technologies:** Python, Pandas, NumPy, Matplotlib, Flask, SQLite, HTML, CSS, JavaScript, Chart.js

## 1. Project Overview

The **Sales Data Analysis System** is a web-based application designed to analyze sales records, validate uploaded CSV files, manage sales data, and display meaningful business insights through an interactive dashboard.

The system helps users understand sales performance, identify data quality issues, compare product revenue, and analyze monthly sales trends.

### Objectives

- Upload and analyze sales data using CSV files.
- Validate sales records and identify invalid data.
- Detect duplicate sales IDs and handle duplicate records.
- Store sales transactions in an SQLite database.
- Calculate total revenue, units sold, and average order value.
- Display product performance and monthly sales trends.
- Generate charts and reports for better decision-making.
- Test the application using sample datasets.

## 2. Key Features

- **CSV File Upload:** Upload sales datasets through the application.
- **Data Validation:** Detect missing headers, invalid dates, incorrect quantities, invalid prices, and missing values.
- **Error Reporting:** Identify invalid records and explain why they were rejected.
- **Duplicate Detection:** Identify duplicate sales IDs and support duplicate handling policies where implemented.
- **Database Management:** Store and retrieve sales records using SQLite.
- **Sales Analytics:** Calculate revenue, total units sold, and average order value.
- **Interactive Dashboard:** Display sales insights and charts.
- **Product Performance Analysis:** Compare revenue generated by different products.
- **Monthly Trend Analysis:** Visualize sales performance over time.
- **Automated Testing:** Verify data processing and validation using Python tests.

## 4. System Architecture

The application consists of the following components:

1. **Frontend:** HTML, CSS, and JavaScript provide the user interface.
2. **Backend:** Flask handles requests and processes uploaded data.
3. **Analysis Module:** Python, Pandas, and NumPy calculate sales metrics.
4. **Database Module:** SQLite stores sales records and product information.
5. **Visualization Module:** Chart.js and Matplotlib display sales trends and product performance.
6. **Testing Module:** Python test cases verify validation and analytical calculations.

### Application Workflow

1. The user uploads a CSV file.
2. The system checks the file structure and validates the records.
3. Invalid records are identified and reported.
4. Valid records are processed and stored according to the application's import rules.
5. The system calculates sales metrics.
6. The dashboard displays updated information and visualizations.

## 5. Database Design

The project uses **SQLite** as its active database.

The database is designed around two main entities:

### Products Table

Stores product information.

- `product_id` — Unique product identifier.
- `product_name` — Name of the product.
- `category` — Product category.
- `created_at` — Record creation timestamp, if maintained by the schema.

### Sales Table

Stores sales transaction information.

- `sale_id` — Unique sales transaction identifier.
- `product_id` — Identifier linking a sale to a product.
- `sale_date` — Date of the transaction.
- `quantity` — Number of units sold.
- `unit_price` — Price per unit.
- `region` — Sales region.
- `total_amount` — Total transaction value, if maintained by the application or schema.

The `schema.sql` file contains the database schema definitions.

## 7. Sales Analytics and Formulas

### Total Revenue

Total revenue is calculated by summing the revenue from sales transactions.

**Formula:**

`Total Revenue = Sum of (Quantity × Unit Price)`

### Total Units Sold

The total number of units sold across all valid transactions.

**Formula:**

`Total Units Sold = Sum of Quantity`

### Average Order Value

The average revenue per sales transaction.

**Formula:**

`Average Order Value = Total Revenue / Number of Sales Transactions`

The exact denominator depends on how the application defines a sales transaction.

### Product Performance

Products can be compared using revenue and sales volume to identify strong-performing products.

### Monthly Sales Trends

Sales are grouped by month to analyze changes in revenue over time.

### Month-over-Month Growth

**Formula:**

`MoM Growth (%) = ((Current Month Revenue - Previous Month Revenue) / Previous Month Revenue) × 100`

If the previous month's revenue is zero, the growth rate requires special handling.

## 9. Installation and Setup

### Prerequisites

- Python 3.10 or later.
- pip package manager.
- A web browser.
- Git, if cloning the repository.

### Step 1: Clone the Repository

```bash
git clone https://github.com/ghosthunter3107/sales-data-analysis-system.py.git
```

### Step 2: Open the Project Folder

```bash
cd sales-data-analysis-system.py
```

### Step 3: Install Dependencies

```bash
python -m pip install flask pandas numpy matplotlib
```

Install any additional dependencies required by the project if they are listed in its configuration or source files.

### Step 4: Run the Application


**Note:** This is a local development address. Other users cannot access your computer's website through this address unless you deploy the application or configure appropriate network access.
