Documented Duplicate Handling Policy (Project Acceptance Specification):

When importing sales records with pre-existing primary keys (sale_id):

  • SKIP (Default Standard): Protects existing records from accidental mutation. Retains the original entry and flags duplicate rows in the import log.
  • OVERWRITE (Data Refresh): Updates existing record attributes (product, quantity, price, total) with incoming fresher data.
  • APPEND (Historical Preservation): Generates an audited unique suffix (e.g. S1001_dup1) to retain both entries without violating primary key integrity.

MySQL Database Entities & DDL

Normalized Relational Architecture matching project specification

schema.sql (MySQL 8.0+) 
-- 1. Products Table (Catalog)
CREATE TABLE products (
    product_id VARCHAR(50) PRIMARY KEY,
    product_name VARCHAR(255) NOT NULL,
    category VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Sales Table (Transactions)
CREATE TABLE sales (
    sale_id VARCHAR(50) PRIMARY KEY,
    product_id VARCHAR(50) NOT NULL,
    sale_date DATE NOT NULL,
    quantity INT NOT NULL CHECK (quantity > 0),
    unit_price DECIMAL(10, 2) NOT NULL CHECK (unit_price >= 0),
    region VARCHAR(100) NOT NULL,
    total_amount DECIMAL(12, 2) GENERATED ALWAYS AS (quantity * unit_price) STORED,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (product_id) REFERENCES products(product_id) ON DELETE CASCADE
);

-- Analytical Queries
-- 1. Monthly Revenue & Quantity Trend
SELECT DATE_FORMAT(sale_date, '%Y-%m') AS month,
       SUM(quantity * unit_price) AS total_revenue,
       SUM(quantity) AS total_units_sold,
       COUNT(sale_id) AS total_orders
FROM sales
GROUP BY month
ORDER BY month ASC;

-- 2. Top-Selling Products Performance Ranking
SELECT p.product_id, p.product_name, p.category,
       SUM(s.quantity) AS units_sold,
       SUM(s.quantity * s.unit_price) AS total_revenue
FROM sales s
JOIN products p ON s.product_id = p.product_id
GROUP BY p.product_id, p.product_name, p.category
ORDER BY total_revenue DESC;
